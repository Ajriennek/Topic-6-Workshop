# Choosing a review approach
10 minutes: read (2), compare in pairs (5), share (3).
For one scenario compare asynchronous review, walkthrough and paired review. Choose an approach using two facts; state a limitation, control and circumstance requiring another reviewer.

A: A focused setup-documentation correction has clear written context. The colleague able to reproduce it works in a different time zone.
B: A cancellation-policy change depends on unfamiliar timing rules. Reviewers understand the codebase but need to clarify the approved business requirements.
C: A short capacity-calculation correction is needed promptly. A knowledgeable reviewer is available now and a reproducing test exists.

Decision record: scenario / choice / alternative / reasons / risk and control / missing information.
